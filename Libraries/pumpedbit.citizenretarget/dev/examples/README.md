# Examples

This folder is reserved for small release examples and smoke-test notes.

Recommended release smoke tests:

1. Copy Libraries/CitizenRetarget from a packaged release into a clean s&box project.
2. Restart the editor or run Compile local.
3. Open CARL -> Open Retargeter.
4. Run Diagnostics and confirm missing dependencies are reported clearly.
5. Retarget one known-good UAL clip.
6. Retarget one known-good Mixamo clip.

Do not commit generated project assets or local .sbox settings here.
